# Lía

**Lía atiende. Vos producís.**

No es una agenda. Es el escritorio del PAS: que no se caiga una renovación, que no quede una cuota en mora, que el cónyuge no se asegure con otro.

## Cómo se vende

Una renovación de auto que no se pierde ya paga meses de suscripción. El WhatsApp no es para “no te despierten”: es para que el cliente pague, renueve y sienta que tiene un estudio.

## Módulos

- Hoy — qué hay que hacer para no perder plata
- Radar — vida al cónyuge, silencio, cotizaciones colgadas
- Cotizar — pipeline de propuestas
- Cobranzas — mora vs calendario
- Renovar — método 90-60-30
- WhatsApp con la marca del estudio
- Auxilio — 0800 de grúa y denuncia
- Caja de comisiones y bóveda

```bash
npm install
npm run dev
```
